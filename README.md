# Информационная система извлечения данных с Rusbuk.ru

Учебный проект (задание на пару).

**Целевой сайт:** [https://rusbuk.ru](https://rusbuk.ru) — букинистический интернет-магазин.

## Что делает система

1. **Парсит** данные о книгах с сайта Rusbuk.ru (название, автор, цена, категория)
2. **Сохраняет** в базу данных SQLite
3. **Позволяет** просматривать, искать и экспортировать данные через веб-интерфейс

> Если сайт недоступен или структура HTML изменилась — автоматически подставляются демонстрационные данные, чтобы система работала на защите.

## Установка и запуск

```bash
# 1. Создать виртуальное окружение
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить интерфейс
streamlit run app.py
```

Откроется браузер: `http://localhost:8501`

---

## Консольный запуск парсера

```bash
python run_parser_console.py
```

## Как пользоваться

1. Слева нажмите **«Запустить парсинг»**
2. Выберите количество разделов каталога
3. Данные появятся во вкладке **«Все книги»**
4. Можно искать по названию, автору, категории
5. Можно скачать результат в CSV
